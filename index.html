DÚVIDAS?

Perguntas frequentes

O que é o Meu Rachão?

O Meu Rachão é uma plataforma para encontrar partidas esportivas, conhecer jogadores e criar seus próprios jogos.

Como encontro uma partida?

Acesse o aplicativo, escolha seu esporte e encontre partidas disponíveis de acordo com os filtros que você definir.

Posso criar minha própria partida?

Sim. Você pode criar uma partida, definir o esporte, local, data, horário e número de jogadores.

Quais esportes estão disponíveis?

O Meu Rachão foi desenvolvido para diferentes esportes, incluindo futebol, basquete e vôlei.

Preciso pagar para usar o Meu Rachão?

As condições de participação podem variar de acordo com cada partida. Consulte os detalhes no aplicativo.

Pronto para jogar?

Encontre uma partida ou crie seu próprio rachão e comece a jogar.
